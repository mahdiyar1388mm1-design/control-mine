# راهنمای آزمون، معیارهای پذیرش و داده‌های آزمایشی — CENTRAL MINE

> تمام داده‌های زیر کاملاً ساختگی و مخصوص توسعه و آزمون مستقل CENTRAL MINE هستند و هیچ داده‌ای از سامانه‌های دیگر کپی نشده است.

## ۱. اجرای خودکار آزمون‌ها

از ریشهٔ مخزن:

```bash
npm test
```

این دستور ابتدا فرانت‌اند (`client/dist`) را بیلد می‌کند و سپس مجموعهٔ کامل تست‌های واحد، مهاجرت/بازگشت دیتابیس، پشتیبان‌گیری رمزنگاری‌شده و آزمون‌های پذیرش سرتاسری (`server/tests/*.test.js`) را روی یک دایرکتوری موقت و ایزوله اجرا می‌نماید (بدون دستکاری دیتابیس توسعه).
