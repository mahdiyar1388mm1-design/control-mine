# CENTRAL MINE — پلتفرم فارسی فروش تجهیزات و خدمات عملیاتی آنلاین

پلتفرم یکپارچه، راست‌چین و موبایل‌محور برای **فروش آنلاین کالاهای فیزیکی** و **ثبت، پیگیری و انجام خدمات عملیاتی** با کنترل دسترسی سمت سرور، فرم‌های خدماتی نسخه‌دار، SLA، تیکت پشتیبانی مستقل، پنل‌های نقش‌محور کارکنان، ممیزی عملیات حساس و گزارش‌های تفکیک‌شده.

---

## تحویل و بهره‌برداری

نصب روی سرور تولید، بدون هیچ مرحلهٔ دستی خارج از این مخزن:

```bash
npm run admin:create -- --phone 09123456789 --name "نام و نام خانوادگی"
npm run mfa:provision -- --all-privileged --write
npm run demo:purge -- --keep 09123456789 --write
npm run backup          # پشتیبان رمزنگاری‌شده + تأیید بازگردانی
npm run monitor -- --url https://example.com
npm run preflight -- --url https://example.com
```

فایل‌های `deploy/` شامل systemd unit‌ها (سرویس، پشتیبان شبانه، پایش ۵ دقیقه‌ای،
نگهداری ماهانه)، نمونهٔ Nginx با TLS و نمونهٔ محیط تولید است. راهنمای گام‌به‌گام:
`docs/05-deployment-backup-rollback.md` §۱۱.

درگاه پرداخت و پیامک به‌صورت آداپتور پیاده شده‌اند: با تنظیم
`CM_PAYMENT_PROVIDER`/`CM_SMS_PROVIDER` و کلیدها، همان مسیرها بدون تغییر کد به
سرویس واقعی وصل می‌شوند؛ تا آن زمان `/health` صادقانه `real_connected: false`
گزارش می‌کند.

## ⚡ پاسخ سریع: «APIها کجا می‌نشینند؟»

**یک پردازه، یک پورت.** این پروژه API جداگانه ندارد؛ همان `server/src/index.js` هم
`/api/v1/*` را جواب می‌دهد و هم فرانت‌اند ساخته‌شده (`client/dist`) را سرو می‌کند.
روی سرور فقط پورت `3000` را باز می‌کنید و Nginx/Caddy دامنه را به آن می‌رساند:

```
https://example.ir  ──▶  :443 (TLS)  ──▶  127.0.0.1:3000
                                           ├── /api/v1/*   API
                                           ├── /uploads/*  فایل‌های عمومی
                                           └── /*          SPA
```

فرانت‌اند هیچ آدرس API مطلقی ندارد (همه `/api/v1/...` نسبی)، پس با هر دامنه‌ای کار می‌کند.
راهنمای کامل: [`docs/05-deployment-backup-rollback.md` §۵](docs/05-deployment-backup-rollback.md).

## راه‌اندازی سریع محلی

پیش‌نیاز: **Node.js 22.5+** (دارای ماژول توکار `node:sqlite`).

```bash
# ۱. نصب وابستگی‌ها
npm run install:all

# ۲. ساخت فایل تنظیمات (برای توسعه هم توصیه می‌شود)
cp .env.example server/.env

# ۳. اجرای مهاجرت دیتابیس و بارگذاری دادهٔ آزمایشی ساختگی
npm run migrate
npm run seed

# ۴. ساخت نسخهٔ تولید فرانت‌اند
npm run build

# ۵. اجرای سرور یکپارچه (API + رابط کاربری روی پورت 3000)
npm start
```

سرور فایل `server/.env` را خودش می‌خواند (بدون `dotenv` و بدون `export` دستی)؛
متغیری که در شل ست شده باشد همیشه بر فایل اولویت دارد.

برای اجرای کامل تست‌های خودکار (بیلد فرانت‌اند + تست‌های واحد + ۲۰ سناریوی پذیرش):

```bash
npm test
```

### بررسی آمادگی پیش از تحویل

```bash
npm run preflight                         # محیط، کلیدها، مجوز فایل‌ها، مهاجرت‌ها، دادهٔ دمو
npm run preflight -- --url https://example.ir   # + سلامت سرور زنده (/health, /ready, sitemap, هدرها)
```

اگر مانع سختی (`BLOCKING`) پیدا شود با کد ۱ خارج می‌شود — مناسب برای CI یا مرحلهٔ استقرار.
قبل از انتشار: `npm run verify` (= تست‌ها + preflight).

### استقرار «خام» روی سرور تازه

```bash
git clone <repo> /opt/central-mine && cd /opt/central-mine
npm run install:all
cp .env.example server/.env && chmod 600 server/.env   # کلیدها + دامنهٔ واقعی
npm run build                                          # خروجی: client/dist
npm run migrate                                        # بدون seed روی تولید
npm run preflight                                      # باید ۰ مانع بدهد
npm start
```

`seed` فقط دادهٔ نمایشی می‌سازد (کاربران دمو با رمز عمومی `Cm@Test1405!`). **روی
تولید اجرا نکنید**؛ اولین مدیر را از مسیر عادی ثبت‌نام بسازید و نقشش را ارتقا دهید.

برای توسعهٔ هم‌زمان با Hot Reload فرانت‌اند:
- در ترمینال اول: `npm --prefix server run dev` (پورت `3000`)
- در ترمینال دوم: `npm --prefix client run dev` (پورت `5173` با پروکسی خودکار `/api` و `/uploads`)

## شفافیت وضعیت اتصال‌های بیرونی در نسخهٔ فعلی

- **درگاه پرداخت بانکی:** روی آداپتور آزمایشی (`sandbox`) با امضای HMAC و کنترل تکرار callback فعال است؛ اتصال بانکی واقعی نیازمند دریافت کلیدهای رسمی کارفرما است و «فعال بانکی» اعلام نمی‌شود.
- **سرویس پیامک OTP:** روی کانال آزمایشی (`sandbox`) با تولید تصادفی امن، محدودیت نرخ و یک‌بارمصرف بودن پیاده‌سازی شده است؛ سرویس پیامک تجاری متصل نیست.
- **موتور LOTH COIN (LTH)، کیف پول ۷ عنوانی، خزانهٔ ۱۵٬۰۰۰٬۰۰۰ LTH و سرچ پروتکل در بک‌اند:** با دقت عدد صحیح `BigInt` (بدون خطای ممیز شناور، از `1.00 LTH` و `0.00000001 LTH` تا `0.000000000001 LTH = 0.00484 IRR`)، لوگوی رسمی برند `CENTRAL MINE`، خزانهٔ پروتکل با ۵ ردیف مصوب (`دارایی`، `مقدار بازار`، `جمع بازگشت استیک`، `جمع بازگشت پایه`، `جمع کارمزد`)، سرچ یکپارچهٔ پروتکل و بازرسی ۳۶۰ درجهٔ موازین در پنل مدیریت/مالی، واریز ۲۴ ساعته سمت سرور با قفل توزیع‌شدهٔ چندسروری، قفل استیک ۳۲۸۵ روزه، نسبت **قفل‌شدهٔ** ۷۰/۳۰ استیک/قابل برداشت (در سطح دیتابیس با تریگر، مهاجرت 013)، برداشت شبا، حساب به حساب و تطبیق دوطرفهٔ دفتر کل حسابداری فعال است. عناوین `میزان تومن` و `TMN` طبق برنامه به فاز بعدی موکول شده‌اند.
- **اعلان Push بیرونی:** غیرفعال است.
