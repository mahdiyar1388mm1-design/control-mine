# CENTRAL MINE — پلتفرم فارسی فروش تجهیزات و خدمات عملیاتی آنلاین

پلتفرم یکپارچه، راست‌چین و موبایل‌محور برای **فروش آنلاین کالاهای فیزیکی** و **ثبت، پیگیری و انجام خدمات عملیاتی** با کنترل دسترسی سمت سرور، فرم‌های خدماتی نسخه‌دار، SLA، تیکت پشتیبانی مستقل، پنل‌های نقش‌محور کارکنان، ممیزی عملیات حساس و گزارش‌های تفکیک‌شده.

---

## راه‌اندازی سریع محلی

پیش‌نیاز: **Node.js 22.5+** (دارای ماژول توکار `node:sqlite`).

```bash
# ۱. نصب وابستگی‌ها
npm run install:all

# ۲. اجرای مهاجرت دیتابیس و بارگذاری دادهٔ آزمایشی ساختگی
npm run migrate
npm run seed

# ۳. ساخت نسخهٔ تولید فرانت‌اند
npm run build

# ۴. اجرای سرور یکپارچه (API + رابط کاربری روی پورت 3000)
npm start
```

برای اجرای کامل تست‌های خودکار (بیلد فرانت‌اند + تست‌های واحد + ۲۰ سناریوی پذیرش):

```bash
npm test
```

برای توسعهٔ هم‌زمان با Hot Reload فرانت‌اند:
- در ترمینال اول: `npm --prefix server run dev` (پورت `3000`)
- در ترمینال دوم: `npm --prefix client run dev` (پورت `5173` با پروکسی خودکار `/api` و `/uploads`)

## شفافیت وضعیت اتصال‌های بیرونی در نسخهٔ فعلی

- **درگاه پرداخت بانکی:** روی آداپتور آزمایشی (`sandbox`) با امضای HMAC و کنترل تکرار callback فعال است؛ اتصال بانکی واقعی نیازمند دریافت کلیدهای رسمی کارفرما است و «فعال بانکی» اعلام نمی‌شود.
- **سرویس پیامک OTP:** روی کانال آزمایشی (`sandbox`) با تولید تصادفی امن، محدودیت نرخ و یک‌بارمصرف بودن پیاده‌سازی شده است؛ سرویس پیامک تجاری متصل نیست.
- **کیف پول، توکن، استیکینگ و اعلان Push:** خارج از محدودهٔ نسخهٔ اول بوده و غیرفعال هستند.
